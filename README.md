I build open tools for marketing, GTM and AI for the Portuguese and Iberian market.
Every tool focused on Portugal has a README in European Portuguese (PT-PT) and English.

## How it works

Each tool lives in its own repository. This one is the index.

| Tool | What it does | Status | Link |
|---|---|---|---|
| geo-check | Checks whether a website is reachable and readable by AI crawlers, and scores it. | Live | [repo](https://github.com/vasco-branco06/geo-check) |
| Awesome Portugal Data | A curated list of open data sources about Portugal for marketing and market research. | Planned | - |
| Portugal Marketing Internships Guide | Where to look for marketing internships in Portugal, when to apply and what to expect. | Planned | - |
| LinkedIn Hooks Bank (PT-PT) | Opening lines for LinkedIn posts, written in European Portuguese. | Planned | - |
| GEO Audit in Portuguese | A guide to auditing a website for AI search, written in Portuguese. | Planned | - |
| Marketing Glossary EN to PT-PT | Marketing terms in English with their European Portuguese equivalents. | Planned | - |
| Power Query Templates for Marketing | Power Query templates for cleaning and combining marketing data in Excel. | Planned | - |
| PT-PT Review Skill for Claude Code | A Claude Code skill that reviews text for European Portuguese spelling and usage. | Planned | - |
| VAT Price Calculator PT/ES | Converts prices with and without VAT at Portuguese and Spanish rates. | Planned | - |
| SPF/DKIM/DMARC Checker Explained | Checks a domain's email authentication records and explains each result in plain language. | Planned | - |
| Portuguese NIF Validator | Checks whether a Portuguese tax number (NIF) is valid, using its check digit. | Planned | - |

## Suggest a tool

If the Portuguese market needs a free tool that is missing here,
[open an issue](https://github.com/vasco-branco06/freetools/issues/new) and describe the problem.
